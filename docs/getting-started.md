# Getting started

This guide takes you from a fresh clone to a running app. The quickest path is the offline demo, which needs no API key and no network access after installation.

## 1. Install

Requirements: Python 3.12 or 3.13, and Git.

```powershell
git clone https://github.com/CaioVenxncio/cryptovision-dashboard.git C:\dev\cryptovision
cd C:\dev\cryptovision

python -m venv .venv
.\.venv\Scripts\Activate.ps1          # Linux/macOS: source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements-dev.txt   # or requirements.txt for runtime only
pip install -e . --no-deps
```

On Windows, clone into a short path such as `C:\dev\cryptovision`. Streamlit contains deeply nested files, and long paths can fail with `WinError 206`.

## 2. Run the offline demo

```powershell
cryptovision-demo
```

The first run builds synthetic data under `.demo/` (about 25 seconds), then starts Streamlit at http://localhost:8501. Later runs reuse the data.

- Every page shows a **Demo mode — synthetic data** notice. The values are generated by CryptoVision and are not market observations.
- The demo research bundle uses a demo protocol on synthetic data. It is not the empirical study.
- Options: `--port 8502`, `--root <dir>`, `--prepare-only` (build the data and exit).

## 3. Use live and local data

1. Copy `.env.example` to `.env` and set `COINGECKO_API_KEY` (a free CoinGecko Demo key). Never commit `.env`.
2. Start the app:
   ```powershell
   streamlit run app.py
   ```
3. **Market Explorer** fetches a CoinGecko snapshot (cached for 15 minutes).
4. **Historical Analytics** needs a local dataset. Build the Binance Vision dataset once (several hundred small archive downloads, each verified by checksum; `cryptovision-data plan` shows the exact count):
   ```powershell
   cryptovision-data collect configs\datasets\binance-spot-1d-top10-20210103.toml --yes
   ```
   The data is licensed CC BY-NC-SA 4.0 by Binance and must not be committed or redistributed. See [data-sources.md](data-sources.md).
5. **Research Lab** shows result bundles produced by `cryptovision-research` (see the [README](../README.md#research-lab)).

## 4. Check the installation

```powershell
pytest                 # offline test suite, no API key needed
ruff check .
```
